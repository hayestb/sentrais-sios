### NIN Forensics Framework
Transforms static playbooks into intelligent workflows through five phases:
1. **Discover**: Initial assessment and resource gathering
2. **Diagnose**: System testing and validation
3. **Design**: Configuration and setup
4. **Deploy**: Activation and live operations
5. **Debrief**: Closeout and reporting

### Temporal Orchestration (M1-M6)
- **M1**: Pre-Arrival (T-48h to T-24h)
